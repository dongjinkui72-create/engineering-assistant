# 工程助手 (Engineering Assistant) v1.0

把**零件图纸**（三视图 / 图片 / PDF / DXF）自动读成参数，在后台驱动 **UG/NX、SolidWorks、CATIA** 建模，
并生成可直接上机床的 **数控加工程序（NC / G 代码）**。

---

## 一、它能做什么

| 环节 | 说明 |
|---|---|
| 读图 | 调用视觉大模型（默认 `qwen3-vl-plus`）识别三视图尺寸、孔位、型腔、槽、沉孔 |
| 装配图 | 自动识别"这是装配图"，列出零件明细，可点选某个零件单独建模 |
| 建模 | 后台自动打开对应 CAD，用真实特征（拉伸/凸台/切除/凹槽）建模并保存 |
| 校验 | 建模后读取 CAD 的实测体积，与理论体积对比，偏差自动写进报告 |
| 加工 | 生成 2.5D 铣削程序：外形轮廓、型腔清角、腰形槽、钻孔（G81/G83），FANUC/通用 ISO 后处理 |
| 输出 | `.prt` / `.SLDPRT` / `.CATPart` / `.STEP` / `.nc` / `.svg` 预览 / 建模报告 |

## 二、运行环境

- Windows 10/11 64 位
- 已安装下列任一（可多选）：
  - Siemens NX 12.0 及以上（本机：`D:\ug\NX 12.0`）
  - SolidWorks 2022 及以上（本机：2024，模板 `C:\ProgramData\SolidWorks\SOLIDWORKS 2024\templates\零件.prtdot`）
  - CATIA V5 R21 及以上（本机：B21，`E:\catia\anzhuang`）
- 能访问大模型 API（默认沿用本机 `.codex\config.toml` 里的地址与 Key）

## 三、使用步骤

1. 双击 `工程助手.exe`
2. 把图纸拖进左上角虚线框（支持 PNG / JPG / PDF / DXF）
3. 点 **识别图纸（AI 读数）**
   - 如果是装配图，下方会出现零件下拉框，选中要建模的零件会重新做一次聚焦识别
4. 检查/修改中间"参数"区（名称、材料、长宽厚、特征表）——识别有误可直接改
5. 勾选目标 CAD（可多选），点 **开始建模 + 生成加工程序**
6. 完成后"结果"页显示：各软件体积校验、文件路径、NC 程序与耗时

> 输出目录：`<程序目录>\out\<零件名>_<序号>\`，每个 CAD 一个子目录。

## 四、API 配置

默认自动读取 `%USERPROFILE%\.codex\config.toml` 的 `base_url` 与 `experimental_bearer_token`（与 ChatGPT/Codex 一致）。
也可在软件里点 **设置** 单独填写（保存到 `%APPDATA%\EngineeringAssistant\settings.json`）。

## 五、当前能力边界（重要）

- 面向 **2.5D 零件**：板类、圆盘类，含通孔/盲孔/沉孔、矩形型腔、腰形槽、台阶。
- **不支持**：回转体车削件（轴、齿轮齿形）、自由曲面、复杂箱体内部结构、装配体自动装配。
  遇到这类图纸，软件会给出零件明细并提示可建模的简单零件。
- NX 建模采用"方块/圆柱 + 布尔运算"实现；个别相切特征会自动加 0.05mm 微量重叠以避开 NX 布尔限制。
- CATIA 不支持中文文件名，软件会自动转成 `Part_xxxxxx.CATPart`（界面仍显示中文名称）。
- NC 程序为通用三轴 ISO 代码，可直接在机床上使用；如需要特定机床/系统格式，可在 NX CAM / SolidWorks CAM 中导入本程序或按同一刀路重新后处理。

## 七、常见问题

**Q：提示"未配置 API Key"？**
A：检查 `.codex\config.toml` 是否存在 `base_url` 与 `experimental_bearer_token`，或在"设置"里手动填写。

**Q：CATIA 第一次很慢？**
A：CATIA 冷启动约 40 秒，软件会自动等待并预热。

**Q：识别尺寸不准？**
A：图纸越清晰越好（建议 ≥1500px 宽）。识别后可在参数表里直接修改再建模。

**Q：NX 报"Tool body completely outside target body"？**
A：说明该特征与已有空腔完全重合（例如孔落在通槽里），属于正常提示，不影响结果。

## 八、建模步骤（v1.1 新增）

识别完成后，右侧「建模步骤」页按人的思路列出全过程，例如：

```
1.【新建长方体】新建长方体 160×100×12 mm，四角 R2
2.【钻孔】在顶面 (0,0) 钻 Ø30 通孔
3.【圆周阵列孔】以 (0,0) 为圆心，Ø90 圆周均布 6×Ø10 通孔
4.【型腔铣削】在顶面 (0,0) 铣型腔 80×50，深 6
```

- **双击**某一步 → 修改坐标/直径/深度/角度/数量/间距等参数
- **上移/下移/删除/启用停用** → 调整或去掉步骤
- **添加步骤** → 手动补孔、型腔、槽、阵列、镜像
- **按步骤重新建模** → 弹窗确认后，严格按新参数重建（并重新校验体积）

识别会做两遍：先提取，再对照图纸复核（可在界面关闭）。

## 九、加工程序由哪款软件输出

界面「加工程序由」可选：

| 选项 | 说明 |
|---|---|
| UG / NX CAM | 程序头标注 NX 后处理 |
| SolidWorks CAM | 程序头标注 SW CAM 后处理 |
| CATIA 加工 | 程序头标注 CATIA 后处理 |
| 内置通用后处理 | 纯 ISO/FANUC，不绑定软件 |

刀路、刀具、加工方式、毛坯由内置工艺规则自动决定；勾选 **AI 辅助生成刀路** 后，
若内置规则不满足（例如特殊材料/特殊槽型），会调用大模型给出刀具与切削参数方案，
校验不通过则自动回退到内置方案。

详见 `功能清单.md`。

## 十、版本兼容

- 支持 NX 12.0+（含 1847 及以后连续版本）、SOLIDWORKS 2022+、CATIA V5 R21+

## 十一、尺寸一致性校验（v1.3）

每次建模后自动做两道校验，结果写进报告：

1. **STEP 尺寸核对**（NX / SolidWorks / CATIA 三款全覆盖）：直接解析 CAD 导出的 STEP，
   读取实际包围盒尺寸、每个圆柱面的半径与轴线位置，逐项和图纸参数比对。
   例：图纸 100×60×12、Ø10@(-30,12)、Ø6@(30,-12) → CAD 实测 100.00/60.00/12.00，孔位 2/2 匹配。
   （NX 的 STEP 由安装目录里的 STEP214 独立转换器导出，不走只读的 NXOpen StepCreator。）
2. **体积 + 质心核对**：CAD 返回的体积/质心与理论值比对（体积偏差 < 1%，质心偏差 < 0.3mm）。
   孔径或孔位错放会立刻让质心偏移，抓得出来。
