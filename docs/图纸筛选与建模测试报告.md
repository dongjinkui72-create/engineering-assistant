## 四、本轮修的 bug：回转体理论体积漏扣顶棱圆角

**现象**：p14 限位器两家 CAD 实测都是 55,413.5，理论值却是 55,617.4，偏差 +0.367%。
两家实体体积完全相同，说明几何是对的、**理论值偏大**。

**定位**：`app/calc.py::part_volume_exact()` 的 `revolve_profile` 分支只扣了特征，
没有扣 `spec.fillet`；而 SW（`sw.py:1994-2003`）和 NX（`nx.py:811-914`）都会在回转实体上
施加 R2 圆角，并且在 `chamfer>0 且 fillet>0` 时按同一规则「倒角被圆角覆盖，跳过」。

**修法**：回转分支补扣 `fillet_v(spec)`（有圆角时）或 `chamfer_v(spec)`（无圆角时），
与两家 CAD 的口径一致。

**效果**：p14 理论值 55,617.4 → 55,411.1，偏差 0.367% → 0.004%。
p13 / p15 / p27 的 fillet=chamfer=0，数值不受影响（仍为 0.000%）。

## 四之二、p28 十字节双面槽：两处修正

**零件**：Ø90×36 圆盘，中心 Ø32 通孔；顶面 X 向 18 宽 × 深 14 直槽贯穿全径，
底面 Y 向同规格直槽，中间腹板 8。fixed spec：`out\_contest\p28_fixed.json`。

### 1. `round_slot_band_area()` 公式错误（理论侧）

旧式 `2·W·√(R²−(W/2)²)` 算的是弦长×槽宽，即把圆内直槽当矩形；
正确截面积是圆被两条平行弦切出的弓形带：

```
A = 2·[ a·√(R²−a²) + R²·asin(a/R) ],  a = W/2
```

R=45、W=18 时 1,587.27 → **1,609.13 mm²**（少算 21.9 mm²，体积高估 0.36%）。
改后 p28 理论体积 170,857.4 → **170,245.14**，与 0.05/0.02 网格收敛值一致。
`tools\regress_steps.py` 21 组回归仍全部零误差。

### 2. SolidWorks 底面切除方向参数用错（实体侧）

`sw.py::cut()` 把「底面开槽」的翻转标记传给了 `FeatureCut4` 的第 2 个参数 **Flip**
（反向切除侧），而该处需要的是第 3 个参数 **Dir**（切削方向）。
改前底面槽 `FeatureCut4` 返回空、`切除失败：腰形槽 90×18`，实测体积 185,157.2（+8.37%）。
改为 `[True, False, bool(flip), ...]` 后底面槽正常切出。

## 六、下一步功能优先级（按性价比）

1. **任意闭合二维轮廓拉伸 / 切除**（`profile_extrude` / `profile_cut`）
   —— 一次补齐 19、20 两件，也能覆盖绝大多数「异形棱柱 / 异形凸台」类零件。
   要点：轮廓由直线 + 真圆弧段组成（禁止连续点拟合），体积用鞋带公式 + 圆弧修正。
2. **放样 / 偏心回转**
   —— 补齐 26 偏心异径管；也可用于后续异径管、弯头类零件。
3. 自由曲面（叶轮、壳体、内衬、主轴支架）—— 需要曲面造型内核，排在最后。

另外建议：UI 增加「人工 spec 覆盖」入口。19、28 这类图自动识图会给出错误结果，
人工修正后的 spec 应当能直接进 steps 和建模，而不是被识图结果覆盖。
