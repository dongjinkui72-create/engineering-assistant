### 仍待修：孔位 y 在 25 / 38 之间漂移 —— **已加判据，现会报警**

**先纠正一个说反的结论**：像素实测证明**图纸真值是 y=±38**（到上边 12mm），
`y=±25` 才是错的。而且 OCR 数字里 `25` 和 `38` **都不存在**
（只有 1,2,4,6,9,10,12,15,30,45,50,65,80,100,160）。

所以判据不是“25 可疑”，而是“**孔心到边的距离必须有出处**”：
- `y=38` → 到上边 `50−38=12` → OCR 有 `12` ✓
- `y=25` → 到上边 `50−25=25` → OCR 没有 ✗

### 已实现（`app/vision.py::_feature_consistency`，证据 1.5）

按轴分别校验，且区分数字来源：

```python
# 出现在 axb 里的数字（如 30x10）不能当“孔心坐标被直接标注”的证据
_loose = _nums - _pairs
_ok_x = _cited(f.x, loose=True) or _cited(L/2 - |f.x|)
_ok_y = _cited(f.y, loose=True) or _cited(W/2 - |f.y|)
# 任一轴无出处 → score 押到 0.45 + uncertain
```

两次返工的教训（都写在注释里了）：
1. **多轴不能合并成 `any()`** —— x 有出处会短路 y，等于没检查
2. **尺寸对里的数字不能当坐标证据** —— `y=10` 会因槽宽 `30x10` 误命中

## P1-old（已归档）零件图识图不稳定：同一张图特征数 6 → 3

### 证据

同一张 `samples/sample_plate.png`，两次运行：

| 运行 | 特征数 | 内容 | 体积 |
|---|---|---|---|
| flow_1110h | **6** | 型腔 80×50 + 槽 30×10 @y=25 + 4×Ø9 @y=±25 | 161,213.6（0.092%） |
| flow_1111a | **3** | 型腔 80×50 + 槽 30×10 @**y=0** + **1×Ø9** @(-65,38) | 164,179.4（0.191%） |

两轮的头部参数完全一致（160×100×12，chamfer 2，R2，confidence 都报 0.95），
**只有特征数量变了**，而且置信度没有因此下降 —— 这是最危险的地方：
`confidence=0.95` 让人以为可信，实际丢了 3 个孔。

`flow_1111a` 的 `blocking` 为 `None`，`uncertain` 为空，也就是说
**系统完全没有察觉这次遗漏**。

### 之前已知的同类现象

- 装配图 `reducer_p1.png`：7 次识别给出 直径 104~136、厚度 10~46，无一次相同
  （已用 `drawing_type == "assembly"` 阻断，见 P3）
- `sample_plate`：多次运行出现过 6 特征 / 3 特征两种

### 建议修法

1. **特征数自洽性检查**：图纸上若有 N 个圆（可从 OCR/图像检测粗算），
   识别出的 hole 数明显少于 N 时应降 confidence 并记 `uncertain`。
   现在的 `_scale_check` 只校验总体尺寸，没有校验特征数量。
2. **同类特征成组校验**：4 个 Ø9 只是「环布四孔」这种最常见模式。
   识别出 1 个 hole 时，应主动检查图上是否还有同直径圆未被收录。
3. **复核（`verify`）不能减少特征**：现有守卫只在
   `n0 >= 2 and n1 < n0` 且 `lost >= max(2, n0//2)` 时拒绝。
   3 特征这一轮首次识别就只有 3 个，复核阶段没有机会发现。
   建议：首次识别特征数 < 3 且图纸含多个圆形时，直接置 `uncertain`
   并降 confidence 到 0.6 以下。
4. **`confidence` 不该只看模型自评**：模型给 0.95，但它漏了 3 个孔。
   建议引入"结构完整性"因子：`confidence = min(model_conf, struct_score)`，
   `struct_score` 由特征数、尺寸自洽性等客观量算出。

### CATIA 圆盘倒角（`app/cad/catia.py::_chamfer_round`）

绕竖轴回转三角环切除，**完全不依赖边引用**（原注释说 V5R21 拿不到稳定边引用）。

截面三角形（草图 u=半径，v=高度）：
```
A = (R-c-1, T+1)    左上，顶面之上的空处
B = (R+1,   T+1)    右上角，实体外
C = (R+1,   T-c-1)  右下，外圆之外
```
斜边 A→C 斜率 −1，经过 (R−c, T) 与 (R, T−c)，即标准 45° 倒角面；
另两条边在实体外，回转切除不会多切。

去料解析值 `V = π c² (R − c/3)`，与 SW 实测独立吻合：
- R=60,c=1 → 187.448（SW 实测 187.448）
- R=52,c=2 → 645.074（SW 实测 645.074）

效果：法兰盘 CATIA 误差 **0.124% → 0.001%**，三家完全一致。
